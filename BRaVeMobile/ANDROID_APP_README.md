# BRaVe Android App — Setup, Build & Run

This module depends on the **Neurotechnology Biometric SDK**, which is **not included** in this repository due to licensing. You must obtain the SDK from Neurotechnology and place the required files locally before building.

---

## Prerequisites

- Android Studio (recent stable version recommended)
- JDK 17+ (or the version specified in the project root `build.gradle`)
- Android SDK with the API levels required by the project
- A valid **Neurotechnology Biometric SDK** license and distribution package

---

## 1. Neurotec SDK — manual setup

Create the following folder structure under `app/`:

```
app/
└── libs/
    └── neurotec/
        ├── <provided .jar files>     ← place JAR files here (root of neurotec/)
        └── scanners/
            └── <provided scanner files>
```

### Steps

1. In `app/`, create the folder `libs/neurotec/` if it does not exist.
2. Copy the **JAR files** supplied with your Neurotec SDK into `app/libs/neurotec/` (directly at that folder’s root — not in a subfolder).
3. Create `app/libs/neurotec/scanners/`.
4. Copy the **scanner files** supplied with your SDK into `app/libs/neurotec/scanners/`.

> **Important:** Use only the JAR and scanner files provided for your licensed SDK version. File names and counts may differ between SDK releases.

### Verify layout

Before building, confirm:

- [ ] `app/libs/neurotec/` contains all required `.jar` files
- [ ] `app/libs/neurotec/scanners/` contains all required scanner files
- [ ] No SDK binaries are missing (build errors about missing classes or native libs usually mean an incomplete setup)

## 2. Restore project dependencies

From the **repository root** (not only `app/`):

```bash
# Windows
gradlew.bat --refresh-dependencies

# macOS / Linux
./gradlew --refresh-dependencies
```

In Android Studio: **File → Sync Project with Gradle Files**.

If you use local secrets or machine-specific config, also ensure:

- `local.properties` points to your Android SDK (usually auto-generated by Android Studio)
- `gradle.properties` is configured per project documentation (use `gradle.properties.example` if provided)

---

## 3. Build

From the repository root:

```bash
# Debug APK
gradlew.bat :app:assembleDebug

# Release APK (requires signing config)
gradlew.bat :app:assembleRelease
```

In Android Studio:

1. Open the project root in Android Studio.
2. Wait for Gradle sync to finish.
3. **Build → Make Project**, or **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Output APKs are typically under:

```
app/build/outputs/apk/
```

---

## 4. Run

### On a device or emulator

1. Enable **Developer options** and **USB debugging** on a physical device, or create an AVD in Android Studio.
2. Select the `app` run configuration and your target device.
3. Click **Run** (▶), or from the command line:

```bash
gradlew.bat :app:installDebug
```

### Scanner hardware

If you use physical biometric scanners, connect supported hardware before testing scanner-related features. Scanner drivers/files must match the files placed in `app/libs/neurotec/scanners/`.

## Troubleshooting

| Symptom | Likely cause | What to check |
|--------|----------------|---------------|
| `ClassNotFoundException` / missing Neurotec classes | JARs not in place | `app/libs/neurotec/*.jar` |
| Scanner not detected | Missing or wrong scanner files | `app/libs/neurotec/scanners/` |
| Gradle sync fails | SDK path or JDK mismatch | `local.properties`, JDK version |
| Native library errors | SDK version / ABI mismatch | Use the SDK build matching your target ABI |
